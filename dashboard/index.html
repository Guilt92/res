Client ACL allow/deny entries applied at runtime — application-layer only, not a firewall

Add entry
Precedence: deny is evaluated first and wins over any matching allow. If no allow matches (or the allow list is empty) the client is refused — fail-closed, so an unconfigured gateway is never an open resolver. Bare IPs become /32 or /128; IPv4-mapped IPv6 clients are matched against both v6 and embedded-v4 rules. Disabled entries are kept but never evaluated.
